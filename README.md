# BULLET BREAK — Web FPS 弾幕 PvP

Three.js + Node.js + WebSocket で動くブラウザ用のオンライン弾幕FPS試作版です。

## 遊び方

1. サイトを開き、名前を入力して「新しい部屋を作成」
2. 表示された **6桁の部屋コード** を友達に共有
3. 友達はコードを入力して「参加する」
4. **1部屋最大5人**でリアルタイムFFA対戦。HPが0になると約2.6秒で復活

PCのChrome/EdgeとiPadのSafariでのプレイを想定しています。
ログイン・インストール・ゲームアカウント登録は不要です。

### 操作：マウスなしのキーボード / iPad キーボード

| キー | 操作 |
|---|---|
| W / A / S / D | 前 / 左 / 後 / 右 |
| 矢印キー | 視点を上下左右に動かす |
| J (押し続ける) | 通常射撃 |
| K | 7方向の扇弾幕（クールダウン4秒） |
| L | 32発のリング弾幕（クールダウン8秒） |
| Shift | ダッシュ（クールダウン3秒） |
| Space | ジャンプ |

### マウス

- マウス移動：視点操作（画面クリックでポインターロック）
- 左クリック：通常射撃
- 右クリック：扇弾幕
- E：リング弾幕

### iPad タッチ操作

- 左下のスティック：移動
- 画面右半分をドラッグ：視点操作
- FIRE：通常射撃、FAN：扇弾幕、RING：リング弾幕
- JUMP：ジャンプ、DASH：ダッシュ
- **マウスは不要です。** キーボードだけでも全操作可能です。
- iPadは横向きでのプレイがおすすめです。

## ローカル実行

Node.js 20以上が必要です。

    npm install
    npm start

http://localhost:3000 を開いてください。別ブラウザや同じネットワークの端末でルームコードを共有してテストできます（端末間でアクセスする場合はサーバーを公開してください）。

テスト：

    npm test

## Render公開

このプロジェクトは **Web Service 1つ** で動きます。静的サイト単独では部屋のWebSocketサーバーが動きません。

| 設定 | 値 |
|---|---|
| Repository | https://github.com/NekoNekoKoneKo222/PVPFPSDANMAKU |
| Runtime | Node |
| Build Command | npm install --no-audit --no-fund |
| Start Command | npm start |
| Instance | Free (試作版) |
| Health Check Path | /healthz |
| Branch | main |

サーバーは Render のPORT環境変数で0.0.0.0にバインドします。
HTTPSで公開するとWebSocketは自動でWSSを利用します。

## 試作版の仕様・制限

- サーバー管理のプレイヤー移動・射撃クールダウン・弾幕・当たり判定・HP・撃破数・リスポーン。
- 6桁ランダムルームコード、最大5人、退室・切断処理、部屋が空になると自動削除。
- 通常射撃、扇弾幕、リング弾幕、ダッシュ、ジャンプ。
- 多重送信や不正な入力に対する基本的な制限。対戦レート対応の本格的なアンチチートではありません。
- サーバーは **単一インスタンスで稼働** させる想定。複数インスタンスでは部屋が共有されません。
- 部屋・スコアはメモリ上の一時データ。デプロイ、再起動、スリープ時に消えます。
- 無料プランではアクセスがないと停止し、初回接続に時間がかかる場合があります。
- 現状はテスト用の自由対戦のみ。マスタリー、ランキングの永続保存、アカウントは未実装です。

## ファイル構成

- public/client.js：3D表示、HUD、キーボード・マウス・iPadタッチ入力
- public/index.html と public/style.css：ロビー・対戦画面
- server/index.js：HTTP・WebSocket・最大5人のルーム
- server/game.js：サーバー権威の移動・弾幕・ダメージ判定
- test/：ゲームロジックテスト、HTTP/WebSocket結合テスト
